# Mini Projekt

**Dataset:** Credit Risk Dataset  
https://www.kaggle.com/datasets/laotse/credit-risk-dataset

**Target:** `loan_int_rate` (Oprocentowanie pożyczki)

Celem projektu jest przygotowanie danych do prostego modelu regresji liniowej, który będzie przewidywał jak wysokość zarobków, wiek czy historia kredytowa wpływają na oprocentowanie, jakie otrzyma klient.
